Seção 05 · Espaçamento

Padding · Gap · Margin

Flex vs Grid

Os dois organizam itens, mas de formas diferentes. Flex = linha ou coluna. Grid = grade com linhas e colunas ao mesmo tempo.

Seção 06 · Layout

O mesmo conteúdo, dois layouts

Os 6 quadrados a seguir são idênticos. Só muda a classe do container.

Flex

flex flex-wrap gap-3

Grid

grid grid-cols-3 gap-3

Flex: os itens "fluem" em linha e quebram conforme o espaço.
Grid: os itens obedecem a uma grade fixa de colunas.
